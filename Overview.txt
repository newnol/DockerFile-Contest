LỆNH BUILD ĐA NỀN TẢNG (Multi-arch)
--------------------------------------------------------------------------------
# Tạo builder (chỉ cần chạy 1 lần)
docker buildx create --name multiarch --use

# Build cho cả amd64 và arm64
docker buildx build \
  --platform linux/amd64,linux/arm64 \
  -t app:contest \
  -f Dockerfile.txt \
  --load .

# Hoặc build và push lên registry
docker buildx build \
  --platform linux/amd64,linux/arm64 \
  -t your-registry/app:contest \
  -f Dockerfile.txt \
  --push .

# Kiểm tra image đã build
docker buildx imagetools inspect app:contest

XÁC NHẬN: Dockerfile này HOÀN TOÀN tương thích đa nền tảng vì:
- Sử dụng Python Alpine base (hỗ trợ amd64/arm64)
- Không có dependencies đặc thù nền tảng
- BuildKit tự động xử lý cross-platform build

--------------------------------------------------------------------------------
# Dừng và xóa container (an toàn)

# Xóa image của bài nộp này (an toàn)

# Xóa dangling images từ bài này (nếu build nhiều lần)
